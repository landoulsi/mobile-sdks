### Detailed Findings & Issues

#### 1. Missing Timeout Plugin Installation (Functional Bug / Dead Code)
* **Location**: [`HttpClientFactory.kt`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/HttpClientFactory.kt#L19-L23), [`createPaymentHttpClient`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/HttpClientFactory.kt#L53-L89)
* **Issue**: The timeout constants in [`HttpTimeouts`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/HttpClientFactory.kt#L19) (`CONNECT_TIMEOUT_MS`, `REQUEST_TIMEOUT_MS`, `SOCKET_TIMEOUT_MS`) are defined, and the function KDoc explicitly states that connect, request, and socket timeouts are configured. However, Ktor's `HttpTimeout` plugin (`install(HttpTimeout)`) is never installed inside [`createPaymentHttpClient`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/HttpClientFactory.kt#L53).
* **Impact**: HTTP calls use default engine timeouts or may hang indefinitely during network drops or slow gateway responses.

#### 2. Potential Plaintext Credential Exposure in Logger (Security / Logging Hygiene)
* **Location**: [`HttpClientFactory.kt`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/HttpClientFactory.kt#L65-L75)
* **Issue**: When `enableLogging` is enabled, the client uses `LogLevel.HEADERS` with a generic `println` logger. In [`KtorGatewayClient`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayClient.kt#L73), requests attach `Authorization: Bearer <publishableKey>`.
* **Impact**: While using `LogLevel.HEADERS` correctly avoids logging request/response bodies (protecting sensitive PAN and CVC payload data), dumping all headers prints authorization tokens to stdout/logcat without sanitization or redaction.

#### 3. URL Concatenation and Trailing Slash Vulnerability
* **Location**: [`KtorGatewayClient.kt`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayClient.kt#L72), [`tokenizeGooglePay`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayClient.kt#L86)
* **Issue**: The endpoints are constructed via string interpolation: `"$baseUrl/tokens"` and `"$baseUrl/payment_methods"`. If `baseUrl` is supplied with a trailing slash (e.g., `https://api.gateway.com/v1/`), this evaluates to `https://api.gateway.com/v1//tokens`.
* **Impact**: Double slashes can lead to unexpected 404 Not Found responses or trigger 301 HTTP redirects (which can drop POST payloads). A URL builder or `baseUrl.trimEnd('/')` should be used instead.
* **Additional Note**: [`createPaymentHttpClient`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/HttpClientFactory.kt#L78) sets `url(baseUrl)` in `defaultRequest`, but [`KtorGatewayClient`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayClient.kt#L59) bypasses relative path resolution by passing the full `"$baseUrl/..."` string, creating duplicate base URL responsibilities.

#### 4. Raw Response Body Leakage in GatewayException
* **Location**: [`GatewayException.kt`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayException.kt#L72)
* **Issue**: In [`throwIfError`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayException.kt#L58), if structured parsing fails, the message is generated as `"Gateway error (HTTP $statusCode): $rawBody"`.
* **Impact**: If a 502/504 gateway proxy or misconfigured endpoint returns a full HTML error page or echoes request fields, untruncated `rawBody` is embedded directly in `Exception.message`. This can cause log clutter or accidental information leakage in crash reporting systems.

#### 5. HTTP 400 Status Mapping Defaults to UNKNOWN
* **Location**: [`GatewayException.kt`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayException.kt#L41-L48)
* **Issue**: In [`mapStatusToErrorCode`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayException.kt#L34), status code 400 (`HttpStatusCode.BadRequest`) is not explicitly handled and falls through to `PaymentErrorCode.UNKNOWN`.
* **Impact**: Client-side validation failures or missing parameters returned as HTTP 400 should map to [`PaymentErrorCode.CONFIGURATION_ERROR`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/model/PaymentResult.kt#L14) or [`PaymentErrorCode.GATEWAY_ERROR`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/model/PaymentResult.kt#L12) rather than `UNKNOWN`.

#### 6. Missing Unit Tests for KtorGatewayClient with MockEngine
* **Location**: [`GatewayDtoSerializationTest.kt`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonTest/kotlin/com/landoulsi/payment/shared/network/dto/GatewayDtoSerializationTest.kt), [`build.gradle.kts`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/build.gradle.kts#L51)
* **Issue**: `libs.ktor.client.mock` was added as a test dependency, but unit tests were only written for DTO serialization.
* **Impact**: There are no tests verifying that [`KtorGatewayClient`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayClient.kt#L59) properly attaches the `Authorization` header, executes HTTP POST requests with correct path routing, handles successful 200 responses, or throws [`GatewayException`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/commonMain/kotlin/com/landoulsi/payment/shared/network/GatewayException.kt#L20) upon receiving 4xx/5xx responses using `MockEngine`.
