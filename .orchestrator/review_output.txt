### Minor Observations & Recommendations

1. **State Preservation Across Activity Recreation**:
   - In [`GooglePayPaymentTaskContract`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/androidMain/kotlin/com/landoulsi/payment/shared/googlepay/GooglePayLauncherContract.kt#L63) and [`GooglePayIntentResultContract`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/androidMain/kotlin/com/landoulsi/payment/shared/googlepay/GooglePayLauncherContract.kt#L120), `pendingTransactionId` is stored in an instance variable. If an Activity undergoes process death or configuration change while the Google Pay sheet is active, a recreated contract instance will revert to `defaultTransactionId`. Supplying `defaultTransactionId` during contract registration mitigates this, but callers relying purely on runtime `input.transactionId` should be aware of this lifecycle constraint.

2. **Null PaymentData with Success Status Edge Case**:
   - In [`GooglePayPaymentTaskContract.parseResult`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/androidMain/kotlin/com/landoulsi/payment/shared/googlepay/GooglePayLauncherContract.kt#L70-L86), if `status.isSuccess` is `true` but `paymentData` is `null`, execution falls through to the status code `when` block with status code `0` (`SUCCESS`), classifying it as a `GATEWAY_ERROR`. Explicitly mapping `status.isSuccess && paymentData == null` to `PaymentErrorCode.UNKNOWN` (as done in [`GooglePayIntentResultContract`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/androidMain/kotlin/com/landoulsi/payment/shared/googlepay/GooglePayLauncherContract.kt#L140-L144)) would improve consistency.

3. **Parsing Logic DRYness**:
   - The fallback parsing logic in [`GooglePayIntentResultContract.parseResult`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/androidMain/kotlin/com/landoulsi/payment/shared/googlepay/GooglePayLauncherContract.kt#L133-L190) mirrors [`DefaultGooglePayClient.parsePaymentResultFromIntent`](file:///Users/ahmed/Work/payment-sdk/mobile/shared/src/androidMain/kotlin/com/landoulsi/payment/shared/googlepay/GooglePayClient.kt#L183-L245). Delegating standalone contract parsing through a shared static method would reduce maintenance surface.
